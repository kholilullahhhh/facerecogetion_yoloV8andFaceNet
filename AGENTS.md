# AGENTS.md

## Project Structure

Three services, each independently runnable:

```
backend/     → Laravel 13, PHP 8.3, MySQL (REST API)
ai-service/  → Python 3.11, FastAPI, YOLOv8s + FaceNet (AI inference)
frontend/    → Next.js 16, React 19, Tailwind, shadcn/ui
```

Default credentials: `admin@smpaisyiyah.sch.id` / `password`

## Commands

### Backend

```bash
cd backend
composer install
cp .env.example .env        # then configure MySQL
php artisan key:generate
php artisan migrate
php artisan serve            # http://localhost:8000
```

After modifying PHP files:
```bash
vendor/bin/pint --dirty --format agent   # auto-formatter, required before commit
php artisan test                          # 2 tests (PHPUnit)
```

### AI Service

```bash
cd ai-service
pip install -r requirements.txt
python main.py              # http://localhost:8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev                 # http://localhost:3000
```

```bash
npm run lint                # must be 0 errors before committing
```

**Windows PowerShell**: `npm` may be blocked by execution policy. Use `cmd /c "npm ..."` or run from cmd.

## Critical Gotchas

### Database: MySQL, NOT PostgreSQL

`.env` uses `DB_CONNECTION=mysql`. The `ilike` operator is PostgreSQL-only — **always use `LIKE`** in queries. This applies to all search/filter logic in controllers.

### Sessions Table Required

`SESSION_DRIVER=database` requires the `sessions` table. If missing, run:
```bash
php artisan session:table && php artisan migrate
```
Also run Sanctum migration: `php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"` then `php artisan migrate`.

### 419 Error on Login

Caused by `$middleware->statefulApi()` in `bootstrap/app.php`. This app uses Bearer token auth (not cookie-based). Remove `statefulApi()` if present.

### Frontend Data Fetching Pattern

Paginated API responses use triple-nested access: `res.data.data.data`

```json
{ "success": true, "data": { "data": [...], "current_page": 1, "last_page": 5 } }
```

After create/delete operations, trigger re-fetch with a refresh counter:
```tsx
const [refresh, setRefresh] = useState(0);
useEffect(() => { /* fetch */ }, [refresh]);
// After mutation: setRefresh(r => r + 1)
```

### AI Service Model Loading

Models load once at startup via `lifespan` context manager in `main.py`. Do NOT use deprecated `@router.on_event("startup")`.

YOLO weights: `ai-service/yolov8s.pt` (root level, not `weights/`)
FaceNet: Falls back to pretrained VGGFace2 if custom weights missing.

## API Response Conventions

All endpoints return:
```json
{ "success": true, "data": ... }
```
Errors:
```json
{ "success": false, "message": "..." }
```

Paginated: `data.data` contains `{ data: [...], current_page, last_page, per_page, total }`
Non-paginated: `data` contains the result directly.

## Routes Worth Knowing

- `POST /api/login` — public, returns Bearer token
- `GET /api/me` — auth check (useful for validating token)
- `POST /api/attendance/recognize` — sends image to AI service, matches embeddings, records attendance
- `POST /api/admin/students/{id}/embeddings` — face registration (multipart, `images[]`)
- `POST /api/attendance/sessions` — create attendance session for a schedule+date
